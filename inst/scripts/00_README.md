# Replication scripts

`replicate_paper.R` reproduces the headline Scale-Ordered Contagion results on
the bundled `g20_returns`: the directional WQTE profiles, the three SOCH tests,
and the endogenous market classification. Run from any working directory after
installing the package:

```r
source(system.file("scripts", "replicate_paper.R", package = "sochcontagion"))
```
